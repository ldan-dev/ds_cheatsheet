### TEXTO PARA LA IMAGEN
Convierte datos de formato ancho a largo con `pivot_longer()` y vuelve a ancho con `pivot_wider()`.

### TEXTO PARA LA PUBLICACION
`pivot_longer()` transforma columnas en filas (formato largo) y `pivot_wider()` realiza la operación inversa. Útil para preparar datos para modelado o visualización.

Si quieres probar este código y aprender más detalles, date una vuelta por nuestro repositorio: https://github.com/ldan-dev/ds_cheatsheet

### CODIGO
R
library(tidyr)
df <- tibble(id=1:3, x1=c(10,20,30), x2=c(5,6,7))
long <- pivot_longer(df, cols = starts_with("x"), names_to = "var", values_to = "val")
wide <- pivot_wider(long, names_from = "var", values_from = "val")
print(long); print(wide)
