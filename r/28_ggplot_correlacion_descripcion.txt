Un gráfico de correlación usa `geom_point()` para puntos y `geom_smooth(method='lm')` para mostrar la relación lineal entre variables.

Si quieres probar este código y aprender más detalles, date una vuelta por nuestro repositorio: https://github.com/ldan-dev/ds_cheatsheet

library(ggplot2)
p <- ggplot(mtcars, aes(x=hp, y=mpg)) + geom_point() + geom_smooth(method='lm', se=FALSE) + labs(title='Correlación')
print(p)
ggsave('grafico.png', plot = p)
